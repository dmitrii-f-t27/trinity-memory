Check a GGUF in your browser

Inspect a public Hugging Face file with the same header parser used by Ternary Check. Results are computed locally for the runtimes pinned in this build.

Reads bounded file prefixes, up to 256 MiB. A prefix can include the start of the weight data; weights are not evaluated. No file is uploaded and no account credentials are sent.

Header acceptance does not prove inference will succeed. For a split model this page checks one file; checking all parts together requires the CLI.
